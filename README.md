# Web de CREZCA

Sitio estático de CREZCA (somoscrezca.netlify.app): `index.html` y `privacidad.html`.

- `media/`: videos y portadas de trabajos de clientes (mp4 livianos y jpg).
- `js/`: GSAP 3.12.5 y ScrollTrigger, servidos desde el propio sitio.
- Testimonios: se cargan en el array `TESTIMONIOS` dentro de `index.html`; la sección aparece sola cuando hay alguno.
